# 港澳台日韩美补源验证（2026-11-25）

本轮筛查 31 个候选地址。13 条线路至少两次取得可解码媒体，并通过人工画面核对。合并后 162 条播放项，其中 42 条公网线路，逐条比对保留原有 149 项。

| 地区 | 新增线路 | 实测画质 |
| --- | --- | --- |
| 香港 | 无 | |
| 澳门 | 澳视澳门、澳门资讯 | 1080p |
| 台湾 | 台视新闻、客家电视台 | 1080p、720p |
| 日本 | Weathernews LiVE、GSTV 日本珠宝 | 720p |
| 韩国 | KTV 韩国国民广播、EBS 1TV、EBS 2TV、EBS Kids、EBS Plus 1 | KTV 为 1080p，EBS 为 720×400 |
| 美国 | NBC News NOW、PBS KIDS | 1080p、720p |

澳视葡文、澳门体育、澳门综艺样本虽可解码，画面是版权提示卡。HOY 未验证完整加密流，港台电视 35 的媒体清单返回 404，因此都未收录。部分入选源曾出现媒体分片中断或超时，其中台视新闻的额外探测失败，此前两次取流通过。

家庭 Mihomo 控制接口按目标地区出口另测了公开入口。澳视澳门、澳门资讯、客家电视台、EBS 1TV 和 NBC News NOW 出现地区出口可达、直连对照未通过的情况。台视新闻在台湾出口的入口响应也有慢于直连的情况。完整媒体解码使用测试时家庭网关已加载的策略。地区出口的 HTTP 结果只代表对应入口在探测当时可达。每条候选的测试结果见 [country-expansion.json](country-expansion.json)。

新分流规则已通过真实 Subconverter 与 Mihomo 配置验证。澳广视暂走香港，其他有对应地区的地址绑定本地配置现有地区组。更新规则订阅并重载后才会在路由器上使用本版规则。[规则验证报告](https://github.com/baixiaoshengofficial/rules/blob/main/reports/iptv-validation.md)
