# 港台日韩优先主流台验证（2026-11-25）

按香港通讯办持牌频道表、台湾 MOD 频道表、日本 TVer 同步直播频道和韩国广播商节目表查找。香港、日本、韩国在独立测试进程中使用实际出口地区已确认的节点，完整取流并解码。测试未修改软路由的现有策略。

| 地区 | 固定地址 | 结果 |
| --- | ---: | --- |
| 香港 | 28 | 新增 HOY 76、77、78。明珠台、无线新闻台和 ViuTVsix 的候选未通过。凤凰香港台部分中转可解码，节目画面及时效未确认 |
| 台湾 | 20 个候选 | 暂缓地区实测。线上可用的七条台湾标签线路经 IPinfo 和 Cloudflare 查询均显示香港出口。已找到台视、中视、华视、民视、公视等候选 |
| 日本 | 35 | 日本电视台、朝日、TBS、东京电视台、富士和 NHK Eテレ的候选未通过。两条日视新闻衍生流中有通过的样本，但复测不稳，且有一条使用已绑定美国的共享 CDN |
| 韩国 | 18 | 新增 SBS JTV 全州联播台。KBS1、KBS2 的官网接口返回临时签名地址，固定 CDN URL 返回 403。SBS 本台和 MBC 等未找到通过验证的固定入口 |

韩国另外核对了三个官网临时播放入口。报告只记录可公开核验的入口类型及测试结果。HOY 76–78 用两条香港出口测试，均为 1920×1080，并使用播放器支持的标准 HLS AES-128 流。HOY 76 另取约 22 秒连续画面，确认正常财经节目。全州联播台两次取得可解码节目画面，另有一次分片下载不完整。它是 720×406 的地方联播线路，台标为 JTV SBS。

主源共 192 项，原有 188 项已逐条核对。Clash 的香港列表包含 HOY 官方入口和另一媒体主机，韩国列表按单一 IP 匹配 JTV。路由器更新订阅并重载后生效。
